# As Crônicas do Saber — Demo 1.2

RPG educativo feito no RPG Maker MV, com desafios de matemática, português e coordenação durante o combate por turnos.

- [Jogar no navegador](https://eliasxbox.github.io/The-Chronicles-of-Knowledge/)
- [Baixar a demo para Windows](https://github.com/EliasXbox/The-Chronicles-of-Knowledge/releases/tag/demo1)
- [Baixar o APK de teste para Android](https://github.com/EliasXbox/The-Chronicles-of-Knowledge/releases/download/demo1/As-Cronicas-do-Saber-Demo1.2-Android.apk)

No Windows, extraia todo o ZIP para uma pasta e abra `Game.exe`.
No Chromebook e no celular, também é possível usar a versão de navegador com toque.
O APK é uma versão de teste para Android 6 ou superior e inclui os arquivos do jogo para uso offline.
A assinatura, a integridade e os arquivos do APK foram verificados. Ainda falta testar a instalação e a execução em um aparelho Android.

Cliente Android: [Altimit Systems MV Android Client](https://github.com/AltimitSystems/mv-android-client), Copyright (c) 2017-2019 Altimit Community Contributors, Apache License 2.0. Os avisos estão incluídos no APK. A estrutura foi adaptada a partir do APK compatível fornecido pelo autor da demo, com novo nome, ícone, identificação e arquivos do jogo.

## Controles

Use setas e Enter para os menus, ou mouse/toque. Nos ataques físicos, espere o anel ficar verde e pressione a tecla indicada ou toque no ponto. As magias educativas apresentam questões de múltipla escolha.

## Arquivos publicados

Esta versão web foi preparada a partir da exportação Android da Demo 1.2 no PC (`www`), incluindo imagens e áudio. `index.html` é a página da demo e `play.html` abre o jogo. Saves locais e arquivos temporários não acompanham a publicação.

Para testar localmente, sirva esta pasta por HTTP e abra `index.html`; abrir o jogo diretamente por `file://` pode impedir o carregamento dos dados.
